## 风险提示
- 嵌套树拖拽语义 (跨文件夹层级/作用域跟随, D010) 是唯一略费事点 — 移动请求条目到新文件夹时, 其变量作用域应随之变化 (由后端解析); SPA 仅负责重排与提交新路径, 不自行重新求值.
- 环境/集合变量值可能含 secrets (环境中), SPA 可明文显示用于编辑, 但保存路径按契约走, 不引入额外脱敏逻辑 (M5-D5 只约束日志/历史).

## 停止条件
- 需引入多页面路由, 或后端契约字段超出 D010 时停止.
- 拖拽需自研而非成熟库时停止 (违反禁止范围).

## 适合 AFK 的原因
- 树/环境/变量的 CRUD 与交互皆由原型变体 B + D010 契约确定, 无产品决策缺口.
