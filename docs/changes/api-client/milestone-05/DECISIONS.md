# MILESTONE-05 决策账本 — SPA 界面原型

## 决策 1: 布局 = 双栏纵向流 (变体 B 胜出)

三变体评审 (A 经典三栏 / B 双栏纵向流 / C 单栏对话流), 用户选定 B:

- **左侧栏** (固定 ~272px): 集合名 + 环境胶囊 + 新建/集合变量按钮; 集合树; 底部 git 行.
- **右主区上下分割**: 上请求构建器, 下响应查看器.
- A (三栏) 落选: 用户习惯纵向请求-响应流; C (对话流) 落选: 历史轮次堆叠非刚需, 抽屉集合树多一步.

## 决策 2: git 入口极简 — 单「同步」按钮

侧栏底部一行: `⎇ main ↑N` + 「同步」. 语义为一键 pull+push 合并式, 不暴露分离的 pull/push, 不展示远端地址等细节. (源自 C 的顶栏设计, 移植到 B 的侧栏.)

## 决策 3: 五个面的具体形态

- **集合树**: 文件夹折叠; 悬停出 ▶ (文件夹级运行) 和拖拽手柄; 请求条目三态徽标 (✓/✗/未运行); 运行失败后条目下内联红字明细, 点击跳该请求的断言 tab; 拖拽排序.
- **请求构建器**: 方法徽章着色 (GET 绿/POST 黄/PUT 蓝/DEL 红); URL 中 `{{var}}` 高亮 + 下方解析预览行 (随环境切换即时变); tabs = Params/Headers/Body/Auth/断言; kv 行无边框悬停显框 + 描述列, 末行回车增行; Auth = 继承集合默认/覆盖/无 三选.
- **响应查看器**: 头行 = 状态徽章 + 时延/大小/时刻 + 断言计数胶囊; 三 tab — Body (JSON 树折叠 + 行号 + 语法着色), Headers, **日志**.
- **日志** (评审中用户新增诉求): 一次请求的完整收发转录 — 连接元信息 (TLS/计时分解), `→` 请求行+头+体, `←` 响应行+头+原始体, 变量按当前环境解析后显示.
- **批量运行**: 无独立面板, 结果内联于树 (徽标 + 红字明细); 文件夹头计数徽章.

## 决策 4: 视觉基调

浅色低饱和暖灰底 (#f5f4f1 系), 单色深色主按钮, 状态语义色 (绿/红/黄) 仅限状态表达; 等宽字体用于 URL/JSON/日志; 无边框输入悬停显框.

## 决策 5: 日志与历史落盘不脱敏 secrets

完整收发转录与 `.local/history/` 落盘均保留原文 (含 Authorization 等), 用户拍板不脱敏 — 自用场景, 事后排查价值大于泄露风险; 历史本就在 gitignored 的 `.local/`, 真秘密的边界靠 secrets 文件不进 git 守住, 不靠脱敏.
